Enable this plugin to journal new work. Disable it to restore the framework's ordinary execution path. Stop active runs before changing backend or disabling.

SSH connection settings stay in Code Execution. Shared SSH recovery requires an existing, verified known_hosts file on this worker.

Backend changes take effect after restart. PostgreSQL uses A0_DURABILITY_POSTGRES_DSN and A0_DURABILITY_RESOURCE_KEY from the server environment. It requires the optional psycopg binary driver.
